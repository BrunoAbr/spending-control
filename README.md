# 💰 Controle de Gastos

Aplicação web para controle de gastos pessoais, desenvolvida com foco em aprendizado e prática de desenvolvimento full stack.

A plataforma permite registrar, visualizar e gerenciar receitas e despesas de forma simples e intuitiva.

## 🚀 Funcionalidades
- Cadastro de usuário (autenticação)
- Login e logout
- Registro de receitas e despesas
- Listagem de transações por mês
- Cálculo automático de:
  - Total de entradas
  - Total de saídas
  - Saldo final
- Remoção de transações

## 🛠️ Tecnologias Utilizadas

### Front-end
- HTML5  
- CSS3  
- JavaScript (Vanilla)

### Back-end
- Node.js  
- Express  
- Jest (testes)

### Banco de Dados
- Firebase (Firestore + Auth)

## 🎯 Objetivo do Projeto
Aplicar na prática conceitos de:
- Arquitetura cliente-servidor
- Autenticação de usuários
- Integração com banco de dados
- Organização de código e boas práticas
- Testes automatizados no back-end
